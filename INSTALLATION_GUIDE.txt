⚡ HƯỚNG DẪN CÀI ĐẶT (3 BƯỚC)

BƯỚC 1: Backup dữ liệu cũ
───────────────────────────
1. Vào thư mục project
2. Copy file: bot.py → bot_v4_backup.py
3. Copy file: bot_save.json → bot_save_backup.json


BƯỚC 2: Deploy bot V5
──────────────────────
1. Thay thế file bot.py bằng: bot_upgraded_v5.py
   $ cp bot_upgraded_v5.py bot.py

2. Kiểm tra requirements
   $ pip install -r requirements.txt

3. Commit & push lên Git (nếu deploy bằng Render)
   $ git add bot.py
   $ git commit -m "Upgrade V5: Tăng win rate 70%"
   $ git push origin main


BƯỚC 3: Restart trên Render
────────────────────────────
1. Truy cập: https://dashboard.render.com
2. Chọn Web Service
3. Kéo xuống "Manual Deploy"
4. Nhấp "Deploy latest commit"
5. Chờ 2-3 phút cho bot khởi động
